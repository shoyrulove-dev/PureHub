## Required phone screenshots

Capture the same current candidate, portrait orientation, at 100% font scale:

1. Home with quick access and today card.
2. Tools catalog and search.
3. Wi-Fi Analyzer network health.
4. Lunar Calendar today and month view.
5. OCR or QR permission explanation before the Android permission dialog.
6. Smart Flashlight main controls.
7. Community with Telegram and Pure Earn clearly separated.

Do not use old beta.50 OCR screenshots, debug labels, personal notifications, real Wi-Fi names, QR contents, account details or device identifiers.

## Reviewer notes

- No account is required for PureHub tools.
- Pure Earn is an external service opened from Community and does not receive the PureHub Android ID, app preferences or stored tool content.
- Camera, microphone, nearby Wi-Fi, location, notifications and screen capture are requested only when the matching tool is used.
- The support report is user initiated. The user can review and edit the diagnostic text before submitting it to GitHub.
- F-Droid distribution is discontinued and must not be mentioned as a current download channel.
