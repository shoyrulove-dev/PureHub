# PureHub 1.0.0-beta.63

Beta 63 improves Wi-Fi Analyzer permissions and Android device compatibility.

- Improved the Wi-Fi scanning permission flow on Android 12 and later.
- Made Wi-Fi hardware optional for installation. Wi-Fi Analyzer shows a message on devices without Wi-Fi hardware.
- Verified 75 unit tests, 15 tests on a Redmi running Android 13, and Android release lint.

This is a prerelease. Check Google Play for availability on your closed-testing account.
