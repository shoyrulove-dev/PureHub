# PureHub 1.0.0-beta.56

PureHub beta.56 simplifies Smart Flashlight so the default screen is faster to use on a phone.

## Smart Flashlight

- Rebuilt the Android screen around one large torch control.
- Kept only brightness and auto-off as quick controls.
- Moved strobe, SOS, screen light, and Morse into a compact More list.
- Removed the colour picker from the PWA and aligned its light view with the native Android flow.
- New Smart Flashlight controls are available in English, Vietnamese, Simplified Chinese, and Spanish.

## Verification

- Android debug Kotlin compilation passed.
- Physical-device debug APK installed successfully on an ARM64 Android phone.
- PWA locale validation, production build, service-worker generation, and prerender validation passed.
